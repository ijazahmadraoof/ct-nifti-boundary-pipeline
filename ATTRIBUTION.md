# Attribution and Project Context

This repository is an independent portfolio reconstruction based on concepts
and technical work performed during the 12-ECTS Special Project:

**Development of an Image-to-Analysis Pipeline for the Modeling of Fracture Processes**

at Bauhaus-Universität Weimar, Chair of Data Engineering in Construction.

The original university project was a collaborative research effort involving
multiple contributors and an existing research codebase.

This repository does not represent or reproduce the complete original research
software.

## Scope of This Repository

The portfolio implementation focuses on areas related to my contribution,
including:

- CT/NIfTI preprocessing concepts
- voxel and physical-coordinate handling
- boundary-condition surface extraction
- STL generation
- metadata preparation for numerical-simulation handover

The implementation in this repository is being reconstructed independently for
educational and portfolio purposes.

Original research datasets and private project material are not distributed
here.

## Reuse of Original Project Material

Any code, figures, data, or documentation originating from the original
research repository should only be reused here when its license and sharing
conditions clearly permit it.

Where original material is reused, the corresponding attribution and license
notice should be preserved.

The preferred approach for this portfolio repository is to reimplement the
relevant concepts independently and demonstrate them using synthetic or
publicly shareable data.
